# グループと Auto Layout 設計

## 目的

プロジェクションマッピングでは、同じ大きさのパネルを決まった間隔で並べる配置がよくある。たとえば LED パネル風の壁、階段の蹴上げ、並んだ窓など。今は面を 1 枚ずつ手で置いているので、間隔をそろえるのも、1 枚の大きさを変えたあとに残りを並べ直すのも手作業になる。

面を「グループ」にまとめ、グループに CSS の flex のような並べ方（方向・gap・揃え・padding）を持たせる。中の面が変わると自動で並べ直されるようにする（Auto Layout）。グループの中にはグループも入れられ、グループどうしを並べて入れ子のレイアウトを作れる。

## ゴール

- 面とグループを木構造（レイヤー）として扱う。グループは入れ子にできる。
- Auto Layout:
  - グループは `direction`（横 / 縦）、`gap`（px）、`align`（先頭 / 中央 / 末尾）、`padding`（px）を持つ。
  - 中の要素が足される・消える・大きさが変わる・順番が変わるたびに、自動で並べ直す。
- グループごとに次の操作ができる。
  - まとめて移動する。
  - まとめて表示・非表示を切り替える。
  - 面の一覧（レイヤー）で折りたたむ。
- 保存先は mapping JSON v2。v1 も読み込める。Export / Import でグループも引き継ぐ。

## やらないこと

- wrap（折り返し）。代わりにグループを入れ子にして作る。
- flex-grow / shrink、要素ごとの margin、justify-content（space-between など）。
- グループ単位の回転・拡大縮小。
- グループ自体に元映像を割り当てること。

## やってはいけないこと

- **Auto Layout の中でも、面の形（四隅の相対位置）を変えられなくしてはいけない。** 歪ませて実物に合わせるのが、このツールの本質だから。
- **v1 の JSON や、今ある mapping を壊したり読めなくしたりしてはいけない。**
- **OBS 出力の描画を重くしてはいけない。** レイアウトの計算はドックで行い、プラグインは結果の座標を描くだけにする。

## 決まっていること

### レイアウトの規則

- 1 つの面の大きさは、その面の四隅を囲む矩形（バウンディングボックス）で測る。
- Auto Layout は面を平行移動させるだけで、形は変えない。
- 面の角はドラッグして形を変えられる。形が変わるとバウンディングボックスも変わり、周りの要素がずれる。
- Auto Layout の中にある面は、面ごとドラッグしても位置を変えられない。位置はグループが決める。
- 子グループの大きさは「中身全体のバウンディングボックス + padding」で決まる。
- 並べ方:
  - 主軸（direction）の向きに、先頭から要素を並べる。要素と要素の間を `gap` だけ空ける。
  - 交差軸は `align` で揃える。基準は、グループの中で一番大きい要素の交差軸の長さ。
  - グループの左上 `origin` から `padding` だけ内側を起点にする。
- 並び順は、レイヤーの子要素の順番。
- 非表示の要素はレイアウトから外す（CSS の `display: none` と同じ）。

### グループの操作

- まとめて移動: グループの `origin` を動かす。
  - ドラッグで動かせる。矢印キーでも 1px（Shift なら 10px）ずつ動かせる。
  - 既存の吸着（グリッド・角・辺・延長線）は、グループのバウンディングボックスの四隅に効かせる。
- 表示・非表示: 実際に表示されるかどうかは「面自身の `visible` かつ、祖先のグループがすべて `visible`」で決まる。
- 折りたたみ: 面の一覧で、グループごとに開いたり閉じたりできる。
  - 開閉状態はドックの中だけで持つ。JSON には入れない。
- グループの作り方: 複数の面を選んで「グループ化」（Cmd+G）。解除は「グループ解除」（Cmd+Shift+G）。
  - 解除すると、中身は今の位置のまま 1 つ上の階層に戻る。
- グループの設定は、グループを選んだときの Inspector で編集する。項目は direction、gap、align、padding、名前。
- 重なり順は、レイヤーの木を深さ優先でたどった順番。後ろほど手前に描く。

### JSON v2

`surfaces` はこれまでどおりフラットなまま、四隅の絶対座標を持つ。座標の値は、ドックがレイアウトを計算した結果。木構造は新しく足す `layers` が持つ。

```json
{
  "version": 2,
  "canvas": { "width": 1920, "height": 1080 },
  "grid": { "size": 20 },
  "surfaces": [ { "id": "s-1", "...": "v1 と同じ" } ],
  "groups": [
    {
      "id": "g-1",
      "name": "パネル列",
      "visible": true,
      "origin": [100, 100],
      "layout": { "direction": "row", "gap": 20, "align": "start", "padding": 0 }
    }
  ],
  "layers": [
    { "group": "g-1", "children": [ { "surface": "s-1" }, { "surface": "s-2" } ] },
    { "surface": "s-3" }
  ]
}
```

- **`layers` の形:** 木の各ノードは `{ "surface": id }` か `{ "group": id, "children": [...] }` のどちらか。木のどこにも出てこない面はない。同じ面が 2 回出てくることもない。
- **`surfaces` の並び順:** `layers` を深さ優先でたどった順番と同じにする。保存時にドックが並べ直すので、プラグインはこれまでどおり配列の順番で描けばよい。
- **プラグイン（C++ core）の変更:**
  - v2 を検証する。対象は、ID の重複、存在しない ID の参照、面の出現が木全体でちょうど 1 回か、`layout` の値の範囲（`gap` と `padding` は 0〜4096、`direction` と `align` は列挙値）、木の深さ（16 まで）。
  - 祖先のグループが非表示の面は描画しない。
  - レイアウトの計算は持たない。
- **互換性:** v1 は「すべての面が最上位に並ぶ v2」として読み込む。ドックが一度保存すると v2 として書き出す。v1 しか読めない古いプラグインに v2 を送った場合の挙動は、エラーにするか、読める範囲だけ表示するかが未定（「未定」を参照）。
- **一貫性の責任:** レイアウトの計算はドックの純粋関数で行う。プラグインは、`surfaces` の座標がレイアウト通りかどうかは検証しない。
  - 理由: 外部ツールが座標だけを直接書き換えても、描画は崩れないようにするため。次にドックで編集したときに、レイアウトどおりの位置に戻る。

### ドック側の構成

- レイアウト計算: `layoutTree(mapping) → surfaces` という純粋関数を置く。reducer のコミットのたびに通す。
  - 角をドラッグしている間も、プレビューとしてリアルタイムに計算する。
- 面の一覧はレイヤーの木として表示し、折りたたみと字下げを付ける。
  - 並べ替えは react-aria-components の Tree か GridList の DnD を使う（使う前に調べる）。

## 実装者に任せること

- Inspector と面の一覧の細かい見た目（デザイントークンと WCAG AA は守る）。
- reducer の action 名や、ファイルの分け方。
- ドラッグ中のレイアウト計算をどう最適化するか。

## ユーザーが決めたこと（builder check の後に確認）

- **Auto Layout の中の面の角をドラッグしたとき:** つかんだ角はカーソルに付いていく。その分、後ろに並ぶ要素がずれる。
  - 主軸で先頭にある要素の、左上側の角を外へ引いたときは、グループの `origin` も一緒に動かして角をカーソルの位置に保つ。
  - Inspector の座標入力は絶対座標のまま扱う。
- **グループ化（Cmd+G）した直後:** 今の並びから設定を推定する。
  - 選んだ面のバウンディングボックスが横長なら `row`、縦長なら `column` にする。
  - `gap` は、今の間隔の平均を四捨五入した値（負なら 0）。`align` は `start`、`padding` は 0。
  - 子の順番は、主軸に沿った位置の順。`origin` は選んだ面のバウンディングボックスの左上。
- **OBS のオーバーレイ:** グループを選んだときは、中にある面をすべて選択中として描く。
  - `selectionJson` には、子孫の面の ID をすべて入れて送る。C++ のオーバーレイと selection は変えない。
- **Import の Scale:**
  - `origin` は縦と横をそれぞれの比率で伸縮する。
  - `gap` は、そのグループの主軸の比率で伸縮する。
  - `padding` は、縦と横の比率のうち小さいほうで伸縮する。
  - 伸縮したあと、レイアウトを計算し直す。

## ユーザーが決めたこと（実装計画のレビューの後に確認）

- **先頭でない要素の角をドラッグしたとき:** Figma と同じにする。要素の幅が広がって後ろの要素がずれ、要素の先頭の辺は「前の要素 + gap」に固定されたままになる。そのため、つかんだ角はカーソルから離れて戻る。`origin` の補正は、要素がどの段でも先頭にあるときだけ行う。
- **Stage でのグループの選択:** Figma と同じにする。
  - グループの中の面をクリックすると、一番外側のグループを選ぶ。
  - ダブルクリックするたびに 1 段ずつ中に入り、最後は面そのものを選ぶ。
  - Cmd+クリックで、一番深い面を直接選ぶ。
  - 選択に足すのは Shift+クリックだけにする（今は Cmd+クリックでも足せるので、動きが変わる。README と手動確認の手順に書く）。
  - 選んだグループは、バウンディングボックスの中のどこからでもドラッグできる。
- **中に入ったあと、別の面をクリックしたとき:** Figma と同じにする。同じ階層の兄弟なら、その階層のまま選ぶ。それ以外は、一番外側のグループに戻る。
- **グループ化（Cmd+G）の条件:** 1 つ以上選んでいれば使える。何も選んでいないときは何もせず、トーストも出さない。ボタン「グループ化」は押せない状態にする。選んだものの親が違うときは何もせず、トースト「同じ階層のものを選んでください」を出す。
  - Cmd+G を OBS のドック（CEF）が横取りしても使えるように、ボタン「グループ化」と「グループ解除」をツールバーに置く。横取りされないかは、手動確認の項目で確かめる。

- **非表示の面のソース:** 自分で非表示にした面も、非表示のグループの下の面も、描かないだけにする。割り当てたソースは OBS の active child のままにして、表示を切り替えてもメディアが頭出しされず、ブラウザやキャプチャのソースが再読み込みされないようにする（今の v1 の動きを保つ）。

## 実装前に決めたこと（私の判断）

- **古いプラグインが v2 を受け取った場合:** エラーにする。今の v1 の検証が `version: 1` 以外を拒否するので、追加の作業はいらない。
  - 本番の出力で、非表示のグループの面が描かれてしまうより安全だから。
  - ドックとプラグインは同じバンドルで配る。
- **グループの中の面を、面ごとドラッグしたとき:** 何もしないのは、ダブルクリックで中に入って面そのものを選んでいるときだけにする。そのときはカーソルを「移動できない」の形にし、Inspector に「グループが位置を決めています」と表示する。面そのものを選んでいないときに押してドラッグすると、Figma と同じく一番外側のグループが選ばれて動く（実装計画のレビューの後に確認）。
  - 並べ替えは、面の一覧のドラッグ&ドロップで行う。
- **座標の意味:**
  - 非表示の面の `corners` には、最後に配置された位置を入れておく。
  - 入れ子になったグループの `origin` は、親のレイアウトの計算結果で上書きする（入力としては使わない）。
  - 非表示のグループは、子と一緒に親の並びから外す。
  - `layoutTree` は、同じ入力に対して同じ結果を返す（冪等）。ドックは、結果が変わらないときは送信しない。これで、送った変更が返ってきたときの照合（echo 判定）がループしないようにする。
- **v2 の検証は厳しくする:**
  - `surfaces` の順番が `layers` を深さ優先でたどった順番と違ったら、エラーにする。
  - v2 では `groups` と `layers` を必須にする。
  - 子のないグループは許す。
  - グループと面の ID は同じ名前空間にし、重複したらエラーにする。
  - 存在しないものを参照していたらエラーにする。`groups` にあるのに `layers` に出てこないグループもエラーにする。
  - 知らないフィールドは、v1 と同じく無視する。
- **編集操作:**
  - グループを削除すると、子もまとめて削除する。一つ上の階層に戻したいときは、グループ解除を使う。
  - 複製は、子まで丸ごとコピーし、ID はすべて振り直す。
  - 空になったグループは残す。
  - Align / Distribute / 矢印キーでの移動は、グループの中にある面に対しては無効にする。グループに対しては、そのバウンディングボックスを基準に `origin` を動かす。
- **選択:** `Selection` に `groupIds` を足す。Stage には、グループのバウンディングボックスのハンドルを描く。
- **吸着とバウンディングボックス:**
  - グループの吸着は、padding を含む外枠の四隅に効かせる。グリッドへの吸着は `origin` に効かせる。
  - 中身がない（または全部非表示の）グループは、大きさを padding×2 とし、`origin` の位置に置く。
- **数値:** JSON の小数は丸めない。
